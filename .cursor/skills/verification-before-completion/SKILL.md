# Verification before completion

Before saying a task is done or a bug is fixed:

1. Run the relevant check (typecheck, design:lint, health endpoint, isolation test, or UI click-through).
2. Report what you ran and the result.
3. If you cannot run it, say so explicitly — do not imply success.
