# BornTask spacing and alignment audit

Measured in the running app at `http://localhost:5174`, signed in as `owner@borntask.com`, against `apps/web/docs/design/*.dc.html`.

Viewport was set to **1440 × 900** CSS pixels (`Emulation.setDeviceMetricsOverride`). Layout viewport stayed 1440 wide for every screen below. `tokens.ts` defines `radius` only (`sm` 6, `md` 8, `lg` 12, `xl` 14). There is no gap or padding scale, so suggestions name the spec pixel value and a radius token when one exists.

Product code was not changed.

A repeated control mismatch is called out once as **Ant control** and referenced below: Ant Design buttons and inputs render at height 36, font 14, weight 400, radius `radius.md` (8), with a label-to-field gap of 8 and label type 14 / 400. Spec buttons on the same jobs are usually height 38 (sometimes 42), font 13.5, weight 600. Spec fields are height 38 (42 on create-workspace), label gap 6, label type 13 / 500.

## P1 - hurts daily use

1. **DA-15 Quick add project and section.** The two selects and the dot sit on a 6px gap inside one chip, and Status wraps off the row. This is the control people hit on every new task.
2. **DA-09 and DA-29 Saved views.** The remove control is flush with the name and deletes the view with no confirmation and no undo.
3. **DA-22 Member remove.** Same missing confirmation. The spec already draws the warning.
4. **DA-10 List add-task.** "+ Add task" starts 130px left of the titles, so the daily add row does not line up with the list you are reading.
5. **DA-05 Shell top bar.** Search and New task are 36px and weight 400 next to a 38px bell, on every screen.

## P2 - polish

- **DA-03, DA-04, DA-26, DA-28** Ant field height 36 and label gap 8, against spec height 38 or 42 and label gap 6. Profile already has the right label; only the control height is short.
- **DA-01, DA-07, DA-16, DA-17, DA-19, DA-21, DA-24** Ant button height 36 / font 14 / weight 400, and the segmented control, against spec 38 / 13.5 / 600 and segment font 13.
- **DA-07, DA-17, DA-19, DA-20** Page padding top 24 against spec 28 or, on My tasks, 32.
- **DA-12, DA-13** Drawer close target and meta row-gap.
- **DA-14** Modal radius `radius.lg` (12) against spec `radius.xl` (14). Same shell on Quick add and Save view.
- **DA-06, DA-11, DA-18, DA-23, DA-25, DA-27** Nav row height 36 vs 34, board column 272 vs 268, palette label padding, section row gap 8 vs 10, defaults intro 14 vs 13.5, workflow column widths.

Command palette rows, list filter chips, board cards, defaults role rows, import step pills, and profile notification columns are already on the spec values.
